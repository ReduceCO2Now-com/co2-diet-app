## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Riverpod 3.x generates `profileProvider` not `profileNotifierProvider`**
- **Found during:** Task 2 dart analyze
- **Issue:** Plan referenced `profileNotifierProvider` but the generated file from Plan 01-04 names it `profileProvider` (Riverpod 3.x convention for class notifier: `@riverpod class ProfileNotifier` → `profileProvider`)
- **Fix:** Used `profileProvider` throughout ProfileScreen
- **Files modified:** lib/features/profile/screens/profile_screen.dart

**2. [Rule 1 - Bug] DropdownButtonFormField `value` property deprecated**
- **Found during:** Task 2 dart analyze
- **Issue:** Flutter 3.33+ deprecated `DropdownButtonFormField.value` in favor of `initialValue`
- **Fix:** All DropdownButtonFormField uses updated to `initialValue`
- **Files modified:** lib/features/profile/widgets/profile_form.dart

**3. [Rule 1 - Bug] `withOpacity()` deprecated**
- **Found during:** Task 1 dart analyze
- **Issue:** `Color.withOpacity()` deprecated; use `withValues(alpha:)` instead
- **Fix:** Updated NavigationBar indicator color to use `withValues(alpha: 0.24)`
- **Files modified:** lib/core/router/app_router.dart

**4. [Rule 2 - Lint compliance] `avoid_types_on_closure_parameters` and `discarded_futures`**
- **Found during:** Task 2 dart analyze
- **Issue:** very_good_analysis requires no explicit types on closure params; Future-returning calls in non-async callbacks need `unawaited()`
- **Fix:** Removed type annotations from closures; wrapped all `ref.read().saveProfile()` / `updateField()` calls in `unawaited()`
- **Files modified:** lib/features/profile/screens/profile_screen.dart, lib/features/profile/widgets/profile_form.dart
