    lib/core/sync/hlc.dart — Hand-rolled HLC (Hybrid Logical Clock) implementation. DO NOT depend on the hlc pub.dev package.
    The class must implement:
      - Fields: final int millis, final int counter, final String nodeId
      - Constructor: const Hlc(this.millis, this.counter, this.nodeId)
      - increment(int wallMillis) → Hlc: if wallMillis > millis, return Hlc(wallMillis, 0, nodeId); else return Hlc(millis, counter + 1, nodeId)
      - receive(Hlc remote, int wallMillis) → Hlc: maxMillis = max of [millis, remote.millis, wallMillis]; if maxMillis == millis && maxMillis == remote.millis, counter = max(counter, remote.counter) + 1; else counter = 0; return Hlc(maxMillis, counter, nodeId)
      - compareTo(Hlc other): compare millis first, then counter, then nodeId lexicographically
      - Implement Comparable<Hlc>
    Note for Phase 7: add drift cap on maxDriftMs before sync ships. Document this as a TODO comment in hlc.dart.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Dart code → SQLite file | User-data Dart writes go through Drift parameterized queries into an on-device SQLite file |
| App process → SQLite file | On Android, file lives in app-private documents dir; on iOS, in app sandbox |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | SQLite raw queries with user input | mitigate | Drift codegen uses parameterized queries exclusively; customStatement is never called with user-supplied data |
| T-02-02 | Tampering | FK constraint bypass | mitigate | PRAGMA foreign_keys = ON in beforeOpen callback of MigrationStrategy; verified by schema_test.dart in Plan 01-07 |
| T-02-03 | Tampering | Clock manipulation affecting HLC ordering | accept | Phase 1 is Local Mode only — no sync; HLC ordering is a Phase 7 concern; TODO comment added to hlc.dart for Phase 7 drift cap |
| T-02-04 | Information Disclosure | SQLite file readable by other apps | accept | drift_flutter uses getApplicationDocumentsDirectory which is app-private on both iOS and Android; no external storage |
| T-02-05 | Tampering | consent_records mutated via update DAO | mitigate | ConsentRecordsDao intentionally has no update or delete methods; insert-only pattern enforced at the DAO API surface |
| T-02-SC | Tampering | npm/pip/cargo installs | accept | No npm/pip/cargo in this plan; pub.dev packages verified in RESEARCH.md Package Legitimacy Audit |
</threat_model>
