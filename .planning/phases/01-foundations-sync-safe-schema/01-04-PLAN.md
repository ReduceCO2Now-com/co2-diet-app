    lib/features/profile/providers/profile_notifier.dart — Riverpod 3.x AsyncNotifier. Add part 'profile_notifier.g.dart';

    import riverpod_annotation, IProfileRepository, UserProfile, CalcTargets, TargetCalculator from domain layer, profileRepositoryProvider from lib/core/di/providers.dart.

    DO NOT import package:drift or AppDatabase.

    @riverpod
    class ProfileNotifier extends _$ProfileNotifier:
      @override
      Future<UserProfile?> build() async:
        - Watch the repository stream: ref.watch(profileRepositoryProvider).watchProfile() — but AsyncNotifier.build is not a stream builder. Use ref.listen on a StreamProvider instead, OR convert to a simple async fetch with ref.invalidateSelf for re-triggering.
        - Recommended approach: In build(), call ref.watch(profileRepositoryProvider).getProfile() and return the result. Then expose the watch stream separately via a profileStreamProvider below.
        - After loading the profile row: call TargetCalculator.derive() with the profile fields (only if targets are not all overridden); attach the result as profile.copyWith(targets: calcTargets).
        - Return the enriched profile.

    saveProfile(UserProfile profile) async:
      - state = const AsyncValue.loading();
      - state = await AsyncValue.guard(() async {
          await ref.read(profileRepositoryProvider).saveProfile(profile);
          return profile;
        });
      - After successful save, call ref.invalidateSelf() so build() re-runs and recomputes targets.

    updateField(UserProfile Function(UserProfile) updater) async:
      - Convenience method for single-field auto-save from the Profile form.
      - Gets current profile from state.valueOrNull; creates a minimal placeholder UserProfile if state is null.
      - Applies updater function and calls saveProfile().

    setLocaleUnits(BuildContext context) — static helper method (not a provider method):
      - Takes a BuildContext. Reads Localizations.localeOf(context).countryCode.
      - US, LR, MM → returns 'imperial'. All others → returns 'metric'.
      - Used by ProfileScreen on first load if profile.units has not been explicitly set by the user.
      - NOTE: This is a pure helper; it does NOT call saveProfile itself. The screen calls updateField() with the result if the profile is new.

    Also add a profileStreamProvider below the class:
      @riverpod
      Stream<UserProfile?> profileStream(Ref ref):
        final repo = ref.watch(profileRepositoryProvider);
        return repo.watchProfile().map((row) {
          if (row == null) return null;
          // Attach computed targets
          final targets = TargetCalculator.derive(
            weightKg: row.weightKg, heightCm: row.heightCm, age: row.age,
            gender: row.gender, activityLevel: row.activityLevel, goal: row.goal,
          );
          return row.copyWith(targets: targets);
        });
      This stream provider is what Plan 01-05 uses in the UI to get reactive updates.

      - Do NOT use AutoDisposeRef — Riverpod 3.x uses unified Ref
      - Do NOT use StateNotifierProvider
      - Do NOT import AppDatabase or UserProfileDao in this file
