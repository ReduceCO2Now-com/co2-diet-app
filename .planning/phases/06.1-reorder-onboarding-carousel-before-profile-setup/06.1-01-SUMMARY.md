# Phase 06.1 Plan 01: Relocate onboarding-completion trigger to Profile Setup Summary

**Moved the `completeOnboarding()` call from the Carousel's two exit buttons to Profile Setup's single forward button, converting the Carousel into a pure pass-through screen — closing the exact bottom-nav-bypass regression class Phase 6's `06-10` fix addressed, now under the reordered Carousel-before-Profile-Setup flow.**

## Accomplishments
- `OnboardingCarouselScreen`'s "Skip intro" and last-slide buttons now both call a synchronous `_goToProfile()` (renamed from the async `_finishOnboarding()`) that only navigates to `/profile` — no `completeOnboarding()` call on either exit path
- Last-slide button relabeled from "Go to Dashboard" to "Set Up Profile"; "Skip intro" left unchanged
- `ProfileScreen`'s onboarding-only forward button relabeled from "Continue" to "Go to Dashboard"; its `onPressed` now awaits `completeOnboarding()` then navigates to `/dashboard` with a `mounted` guard — the terminal action of the onboarding flow
- New dedicated widget test file `onboarding_carousel_screen_test.dart` (3 tests) closes a Wave 0 test-coverage gap for the Carousel screen
- `onboarding_gate_test.dart` extended with a button-tap trigger test (asserts `completeOnboarding()` fires and Dashboard is reached) and a Carousel nav-hide regression test (bottom nav absent on `/onboarding-carousel` pre-completion); the stale test previously describing the Carousel as the trigger site was renamed to reference Profile Setup, with its assertions left byte-for-byte unchanged
- `app_router.dart`'s `AppShell` doc comment and `onboarding_gate_provider.dart`'s flow-order/historical-bug-fix doc comments updated to describe Profile Setup (not the Carousel) as the current `completeOnboarding()` call site and the new Carousel-before-Profile-Setup order — zero logic changes; `onboardingOnlyRoutes`/`allowedPreOnboarding` route-guard membership untouched
