<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| CDN pack/delta binary content | Untrusted bytes flow from a network response into on-disk files before verification (checksum happens one plan later, in the orchestrating repository) |
| Live SQLite ATTACH/DETACH while AppDatabase is open | A concurrency boundary, not a data-trust boundary -- getting this wrong corrupts local reads, it does not leak data |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
