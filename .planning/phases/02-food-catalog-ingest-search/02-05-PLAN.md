    - onQueryChanged('a') (1 char) immediately sets state = AsyncData(FoodSearchState.prompt()); no Timer starts

    - _search when repo.searchLocal returns non-empty list: state = AsyncData(FoodSearchState.results(items)); no AsyncLoading
    - _search when repo.searchLocal returns [] and connectivity is none: state = AsyncData(FoodSearchState.offlineNoResults())

    - _search when repo.searchAndCache throws NetworkException: state = AsyncData(FoodSearchState.networkError(e.message))
    - retry(query) calls _search(query) immediately (no debounce)
    - Timer is cancelled via ref.onDispose to prevent dart:async leak
  </behavior>

  Part file: `part 'food_search_notifier.g.dart';`

  Class `@riverpod class FoodSearchNotifier extends _$FoodSearchNotifier`:

  STATE: `AsyncNotifier<FoodSearchState>` — the Riverpod 3 codegen base class is generated from `@riverpod`.

  FIELDS:
  - `Timer? _debounce;`
  - `String _lastQuery = '';`

  LIFECYCLE: Register `ref.onDispose(() { _debounce?.cancel(); });` in `build()`.

  `@override Future<FoodSearchState> build() async { ref.onDispose(() => _debounce?.cancel()); return const FoodSearchPrompt(); }`

  METHOD `void onQueryChanged(String query)`:
  - Cancel existing debounce: `_debounce?.cancel();`
  - If `query.length < 2`: `state = const AsyncData(FoodSearchPrompt()); return;`
  - Otherwise: `_debounce = Timer(const Duration(milliseconds: 300), () => _search(query));`

  METHOD `void onQuerySubmitted(String query)`:
  - `_debounce?.cancel();`
  - If `query.length >= 2`: `_search(query);`

  PRIVATE METHOD `Future<void> _search(String query)`:
  - `_lastQuery = query;`
  - Get repo: `final repo = ref.read(foodCatalogRepositoryProvider);`
  - Local search (NO state change to loading first — per locked decision; local is instant): `final local = await repo.searchLocal(query);`
  - If `local.isNotEmpty`: `state = AsyncData(FoodSearchResults(local)); return;`
  - Check connectivity: `final connectivity = await Connectivity().checkConnectivity();`
  - If `connectivity.contains(ConnectivityResult.none) || connectivity.isEmpty`: `state = const AsyncData(FoodSearchOfflineNoResults()); return;`
  - API fallback — NOW set loading: `state = const AsyncLoading();`
  - `state = await AsyncValue.guard(() async { final apiItems = await repo.searchAndCache(query); return FoodSearchResults(apiItems); });`
  - But if the guard caught a `NetworkException`, we want the specific error state, not a generic AsyncError. So instead:
    ```dart
    try {
      state = const AsyncLoading();
      final apiItems = await repo.searchAndCache(query);
      state = AsyncData(FoodSearchResults(apiItems));
    } on NetworkException catch (e) {
      state = AsyncData(FoodSearchNetworkError(e.message));
    } catch (e, st) {
      state = AsyncError(e, st);
    }
    ```

  METHOD `void retry(String query)` — `_search(query);`

  NOTE on `connectivity_plus` API: In connectivity_plus 7.x, `checkConnectivity()` returns `List<ConnectivityResult>` not a single result. Use `.contains(ConnectivityResult.none)` and handle the case where the list is empty as also "no connectivity". Do NOT use `== ConnectivityResult.none` (single-value comparison) as this API changed in connectivity_plus 5+.
