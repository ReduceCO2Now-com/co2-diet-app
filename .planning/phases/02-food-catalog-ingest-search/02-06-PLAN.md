<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User text input → TextField → notifier | Raw user text enters the search field; must be passed to notifier (which sanitizes it in the DAO layer) |
| External food data → UI | Food names and brand strings from the OFF catalog are displayed as-is; they may contain unusual Unicode |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-06-01 | Tampering | FTS5 query via TextField onChanged | mitigate | Sanitization happens in FoodCatalogDao._sanitizeFts5Query (Plan 02-03); the UI passes raw string to notifier which passes it to the DAO — the DAO is the sanitization boundary |
| T-02-06-02 | Information Disclosure | Food item brand/name containing PII-like strings from OFF | accept | OFF is a public-domain product database; brand and product names are not PII; displayed read-only in the UI |
| T-02-06-03 | Denial of Service | shimmer package rendering on low-end Android | accept | Shimmer is only shown on the API fallback path (not local); fixed 5-row count; no infinite list |
| T-02-06-04 | Tampering | "Try again" button calling retry with empty query | mitigate | Button only appears in NetworkError state which is only reached after a query of length >= 2 was fired; `_controller.text` at that point is non-empty |
</threat_model>
