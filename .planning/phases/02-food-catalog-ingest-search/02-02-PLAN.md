  <action>Create `tools/ingest_off.py`. This script must be callable as `python3 tools/ingest_off.py <jsonl_gz_path> <output_db_path>` with an optional `--help` flag. It must also accept `--sample N` to process only the first N records (for CI/testing without the full 5 GB dump).

  The script must implement the following exactly:

  SCHEMA — execute both DDL statements in one `executescript` call on first run:
  1. `CREATE TABLE IF NOT EXISTS products (barcode TEXT PRIMARY KEY, product_name TEXT NOT NULL, product_name_en TEXT, brand TEXT, calories_100g REAL, protein_100g REAL, carbs_100g REAL, fat_100g REAL, categories_tags TEXT)`
  2. `CREATE VIRTUAL TABLE IF NOT EXISTS products_fts USING fts5(product_name, product_name_en, brand, content='products', content_rowid='rowid', tokenize='unicode61 remove_diacritics 2', prefix='2 3 4')`

  FILTER — per locked decision (D-03 per CONTEXT.md): include a row if and only if BOTH conditions hold:
  - `countries_tags` list contains at least one value from the EU_COUNTRY_TAGS set (see RESEARCH.md Code Examples for the full set including en:germany, en:france, en:austria, en:netherlands, en:belgium, en:spain, en:italy, en:poland, en:sweden, en:denmark, en:finland, en:portugal, en:switzerland)
  - `completeness` field (float) is >= 0.6; treat missing/None as 0.0
  - `product_name` (top-level field) is non-empty after strip()

  FIELD EXTRACTION from JSONL record dict:
  - `barcode`: `p.get('code')`
  - `product_name`: `p.get('product_name', '').strip()` (skip row if empty)
  - `product_name_en`: `p.get('product_name_en')` — None if absent (assumption A1 in RESEARCH.md; script must handle None gracefully)
  - `brand`: `p.get('brands')` (may be None)
  - `calories_100g`: `p.get('nutriments', {}).get('energy-kcal_100g')`
  - `protein_100g`: `p.get('nutriments', {}).get('proteins_100g')`
  - `carbs_100g`: `p.get('nutriments', {}).get('carbohydrates_100g')`
  - `fat_100g`: `p.get('nutriments', {}).get('fat_100g')`
  - `categories_tags`: `','.join(p.get('categories_tags', []))` — empty string if absent

  STREAMING — use `gzip.open(jsonl_gz_path, 'rt', encoding='utf-8')` and iterate line by line. Parse each line with `json.loads()`. Accumulate into a batch list; call `_flush(conn, batch)` every 10,000 rows, then `batch.clear()`. Flush any remaining rows after the loop.

  INSERT — use `executemany("INSERT OR IGNORE INTO products (barcode, product_name, product_name_en, brand, calories_100g, protein_100g, carbs_100g, fat_100g, categories_tags) VALUES (?,?,?,?,?,?,?,?,?)", batch)` followed by `conn.commit()` in `_flush`.

  FTS INDEX — after all rows are flushed, run ONE bulk populate: `conn.execute("INSERT INTO products_fts(rowid, product_name, product_name_en, brand) SELECT rowid, product_name, product_name_en, brand FROM products")` then `conn.execute('PRAGMA page_size = 4096')`, then `conn.execute('VACUUM')`, then `conn.commit()`.

  PROGRESS — print to stderr every 50,000 rows processed: `f"[ingest] {n_processed:,} rows processed, {n_inserted:,} inserted"`.

  ERROR HANDLING — if the JSONL line fails `json.loads()`, print a warning to stderr and continue (do not crash on malformed records).

  CLI — use `argparse`: positional `jsonl_gz` (path to `.jsonl.gz` file), positional `output_db` (path to write SQLite), optional `--sample N` (int, stop after N records), `--help`. If the output DB already exists, print a warning and exit with code 1 (avoid overwriting without explicit delete by the developer).

  IMPORTS: `argparse`, `gzip`, `json`, `sqlite3`, `sys` from stdlib only. No third-party packages — the script must run with Python 3.8+ without pip install.</action>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| OFF JSONL → SQLite | External data source; individual records may be malformed or contain unexpected values |
| Developer workstation → tools/ingest_off.py | Script runs with local filesystem write access |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-02-01 | Tampering | off_reference.sqlite (build artifact) | mitigate | Script uses `INSERT OR IGNORE` (no silent overwrite); existing-DB guard exits with code 1 before any write; developer must explicitly delete DB before re-run |
| T-02-02-02 | Denial of Service | Python ingest (memory) | mitigate | Streaming line-by-line with 10,000-row batch flushes; no full-file load; eliminates OOM risk per Pitfall 7 in RESEARCH.md |
| T-02-02-03 | Tampering | OFF JSONL data quality | accept | OFF is a public-domain dataset; individual malformed records are skipped with stderr warning; no PII involved |
| T-02-02-SC | Tampering | npm/pip/cargo installs | accept | No third-party packages installed; script uses Python 3 stdlib only |
</threat_model>
