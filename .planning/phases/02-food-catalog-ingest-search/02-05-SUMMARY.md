## Decisions Made

- **Pure Dart 3 sealed class (no Freezed):** State variants are simple value objects; Freezed's abstract class pattern is documented for domain entities only. Dart 3 `sealed` + `final class` is lighter and equally exhaustive.
- **Static factory methods:** `FoodSearchState.prompt()` etc. are static methods returning instances of the concrete subclasses. This pattern mirrors the planned API from RESEARCH.md Pattern 6 and is idiomatic for the notifier's state assignment calls.
- **`unawaited()` for fire-and-forget:** `onQueryChanged` and `onQuerySubmitted` are void methods that call an async `_search()`. Dart's `discarded_futures` rule (very_good_analysis) requires explicit `unawaited()` annotation.
- **`on Exception catch` not bare `catch`:** very_good_analysis `avoid_catches_without_on_clauses` requires typed catch clauses; the catch-all arm uses `on Exception`.
- **`foodSearchProvider` (Riverpod codegen naming):** Riverpod 3.x strips the "Notifier" suffix from the class name. `@riverpod class FoodSearchNotifier` generates `foodSearchProvider`, not `foodSearchNotifierProvider`.
