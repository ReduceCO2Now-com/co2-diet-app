<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User query input → FTS5 MATCH clause | User text enters FTS5 query; metacharacters can cause parse errors or unintended logic |
| Flutter assets → file system | GZip decompression writes to app documents directory; path must be derived from path_provider, not user input |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-03-01 | Tampering | FTS5 MATCH query (user input) | mitigate | `_sanitizeFts5Query` strips all FTS5 metacharacters (`"`, `*`, `OR`, `AND`, `NOT`, `NEAR`, `^`) before building MATCH expression; parameterized via `Variable.withString()` (Pitfall 5 from RESEARCH.md) |
| T-02-03-02 | Elevation of Privilege | ATTACH DATABASE path | mitigate | `offRefPath` is always derived from `path_provider.getApplicationDocumentsDirectory()` in `FirstLaunchExtractor`; never from user input (Pitfall 4 from RESEARCH.md) |
| T-02-03-03 | Denial of Service | FTS5 2-char minimum not enforced in DAO | mitigate | `searchLocalFoods` returns [] if sanitized query is empty; caller (FoodSearchNotifier in Plan 02-05) enforces 2-char minimum before calling DAO |
| T-02-03-04 | Tampering | GZip decompression of bundled asset | accept | Asset is bundled in the APK/IPA and cannot be substituted at runtime without compromising the app binary itself; no additional signature check needed at this trust level |
| T-02-03-SC | Tampering | New package installs (openfoodfacts, archive, shimmer, connectivity_plus) | mitigate | All four packages verified [VERIFIED: pub.dev] per Package Legitimacy Audit in RESEARCH.md; no [ASSUMED] or [SUS] packages |
