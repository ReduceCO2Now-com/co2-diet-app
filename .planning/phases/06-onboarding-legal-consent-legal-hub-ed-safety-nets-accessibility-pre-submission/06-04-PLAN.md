## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| Client → local `consent_records` table | Durable legal-evidence write, append-only, never updated/deleted except full wipe |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-04-01 | Repudiation | User disputes having given consent | mitigate | Every write carries a real UTC timestamp (Drift default), the exact app version, the exact document version, and the exact checkbox set accepted — `ConsentRecordsDao` has no update/delete method, so no code path can retroactively alter a past consent event |
| T-06-04-02 | Tampering | Local SQLite file edited directly (rooted/jailbroken device) to backdate a consent record | accept | Out of scope for a local-only unencrypted SQLite app (same residual-risk posture as every other table); the *application layer* offers no tamper path, which is the actionable mitigation within this app's threat model |
