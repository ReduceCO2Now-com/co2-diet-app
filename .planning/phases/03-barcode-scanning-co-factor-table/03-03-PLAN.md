## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Camera feed → Dart onDetect callback | Barcode raw values from ML Kit enter Dart code as String |
| Dart → OFF API (barcode lookup step 3) | Barcode string leaves the device over HTTPS |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-03-01 | Tampering | BarcodeScanNotifier.lookupBarcode | mitigate | Barcode string passed to DAO via `Variable.withString()` — parameterized SQL (enforced in Plan 02 DAO). Max-length guard in DAO (>13 chars → null). |
| T-03-03-02 | Denial of Service | BarcodeScanScreen._handleBarcode | mitigate | `_processing` boolean guard — mandatory before any async work. `unawaited(_controller.stop())` prevents additional onDetect fires. |
| T-03-03-03 | Elevation of Privilege | Camera permission | accept | OS-level permission managed by mobile_scanner + permission_handler. No app-level permission bypass possible. |
| T-03-03-04 | Information Disclosure | OFF API barcode lookup (step 3) | accept | Barcode is a product identifier (public information). No PII is sent to OFF API. Connectivity check already present for API fallback (Phase 2 pattern). |
| T-03-03-SC | Tampering | mobile_scanner/permission_handler/app_settings package install | mitigate | All three packages verified in RESEARCH.md Package Legitimacy Audit (pub.dev 160/160, established publishers).
